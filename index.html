02the gap

Code that runs on a laptop is not a product.

Between a merged pull request and a customer actually being served, there is a long, unglamorous distance. Something has to carry the code across it — and then keep it alive while the world changes underneath it.

That distance is where things quietly break. Not in the algorithm. In the gap.
